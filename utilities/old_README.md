## Getting started

> [!WARNING]
> The latest release of the **G-PEARL**, has been developed for screen resolutions of 1920x1080. Resizing of the window is supported but it is not tested on multiple displays with different resolutions. In case of issues related to the screen size, please, move the main window manually if possible.

## MATLAB version and toolboxes

> [!NOTE]
> In order to run **G-PEARL** on your system, we suggest to install **MATLAB 2024b** or more recent releases and the following toolboxes.
